Seura Photos cache

This folder holds thumbnails and an index of your photo library, so large
folders open instantly. Everything here is rebuilt automatically from your
photos and their edit files (the .seura.json files beside each photo).

It is safe to delete this folder at any time. Seura Photos will rebuild it,
which takes a while for a large library. To start the thumbnails afresh,
Clear in Seura's Settings is quicker: it keeps the index.

Rebuilding the index means reading every edit file again. In a folder
synced by OneDrive, iCloud or another cloud service, edit files that are
only in the cloud are downloaded to do that. They're small, and your
photos themselves aren't downloaded.

Your photos and your edits are never stored here.
