# Messages and notices (M3 slice 11c)

- **Built as the design session answered (INT-6; design answers, 2026-10-27).** The last action's result ("Moved 3 photos to the Recycle Bin.", an undo, read-only photos skipped) is now a brief message near the bottom of the photo area, centred: surface background, a border, a soft shadow, at most 480 px wide. It shows for about 6 seconds, or until the next one, and never blocks anything: the pointer passes through it. It's the same in the Library and the Viewer, and no longer under FOLDERS or in the Viewer's status bar, which goes back to the zoom level and the keys. Nevada had found the sidebar's place easy to miss.
- **The message's region is always there, empty between messages,** so screen readers announce each new one. The tests that counted on a single `status` on the page now ask the status bar for its own.
- **The Viewer shows the notice bar too:** FIL-4 with Start over, FIL-5 and FIL-7, at the top of the photo area. The stage sits below the bar, so the photo is fitted to the space that's left rather than drawn under it. The bar is about the photo shown, where the Library's is about the selection, so it now takes the photos it's about. What Start over kept clears when the Viewer moves to another photo, as it does when the Library's selection changes.
- **The notice bar's styles:** only a problem to act on (an unreadable edit file, with Start over) takes `dangerSubtle`. FIL-7 is a caution: the warning icon on the plain `accentSubtle` bar. FIL-5 and the kept-files bar have the info icon.
- **The delete confirmation's restore-both line is folded into its text** (BRW-9): with an edit file, "Its edits, tags, and rating are in a small file beside it, which goes too. To get everything back, restore both from the Recycle Bin." ("put both back from the Trash" on the Mac); without one, "You can restore it from the Recycle Bin." The plural for several photos says "restore the photos and their files".
- **For the screenshots the design session asked for,** a script in the scratchpad makes a four-photo library with one of each notice and a Seura folder of its own, so they're taken without Nevada's library.
