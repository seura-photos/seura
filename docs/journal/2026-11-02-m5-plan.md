- **A change of order, Claude Code's suggestion:** export before copy and paste, though the milestone plan lists them the other way round. Since 0.3, edits can be seen in Seura but can't be taken out of it.
- **Found while planning, all raised as questions rather than decided:**

  - `xmp_toolkit`, which the technical design names, wraps Adobe's C++ toolkit, and export only needs a small new packet. Claude Code suggests writing that itself, which would change the technical design.
  - The format says a paste replaces a stage's operations, which sits awkwardly with keeping other apps' operations (FIL-5).
  - LIB-9 lists editing among what downloads a photo, while pasting and presets need no pixels, as rotate doesn't.
