# iPhone photos look brighter in Photos: HDR, not colour

- **Nevada noticed**, while doing the Display P3 check (#25), that iPhone HEIC photos look brighter in Apple's Photos and Preview than in Seura on his MacBook Pro.
- **Claude's first guess was HDR:** iPhone photos carry a gain map that HDR screens use to brighten highlights, and Seura shows only the standard picture. But switching the display to a preset without HDR still left a difference, so Claude suggested a second suspect, the colour hand-off from Seura's canvas to the screen (a limitation the technical design had listed to verify), and a test to tell them apart: compare a HEIC and a JPEG in each display preset.
- **Result:** JPEGs matched in every preset; only HEICs differed, and only in some. So Seura's colour reaches the screen correctly, and the difference is HDR: many presets keep some HDR headroom when the screen isn't at full brightness, and Photos uses it. #25's colour check passed.
- **HDR display isn't in the v1 spec,** so whether and when Seura shows it went to the design session as #60.
- **A dead end on the way:** Claude looked for a switch in Photos to turn HDR off and found none; the display presets were the way to compare.
