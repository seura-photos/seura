# Where the version is shown (design session)

- **Nevada noticed** that 0.2 shows its version nowhere on Windows. With no menu bar there, nothing had taken over its jobs: About, and also Settings and Clean up, which the user flows still placed in "the App or Edit menu" and "File → Clean up".
- **Claude's recommendation, taken by Nevada:** a ⋯ button at the right end of the toolbar on Windows, as recent Windows apps do, holding About now and Settings and Clean up when they're built. macOS keeps its menu bar, so each platform has one place for these commands (ACC-4).
- **About (SET-5)** shows the version selectable and with Copy, so early testers can say which build a problem is in. Planned for 0.3; 0.2.1 had already shipped.
