# 2026-11-12: Drafting the M7 plan

- **Nevada asked Claude Code to draft the M7 plan** once M6 was recorded. It has fifteen slices, 0 to 14, and twelve questions, each with a suggestion. Three of the questions are Nevada's: code signing, the Windows install location (#70), and the beta's testers.
- **What's missing to start:**
  - Settings and Clean up have no wireframes or mockups yet, so their layouts are questions for a design session.
  - Code signing hasn't been priced, though the milestone plan wanted it "before the beta".
  - The edit format is still marked draft, with no open issues, so its 1.0 release is a status, a changelog and a tag.
- **Claude Code's suggestions that shape the most work:**
  - The update manifest lives on the website, so beta testers on pre-releases are offered fixes; GitHub's "latest release" address skips pre-releases.
  - On the Mac, Clean up's full reset stands in for an uninstaller, since dragged apps have none.
  - The user guide is a website page written in a design session, from a fact sheet Claude Code supplies and then checks against the app.
- **A rule for secrets, new in this plan:** signing certificates, the Apple account and the updater's private key are Nevada's, stored only as GitHub Actions secrets. Claude Code writes the steps that use them and never handles their values.
- **Carried in:** Node 26 (#156), Google Drive and Dropbox (#162), decoding colors in full (#188), next-photo speed on Windows (#190), #112 with Developer ID, #254, and #70. The issues without a milestone, #217, #255, #258 and #264, are slice 8's fixes before the beta.
