# Freeing space after Seura downloads photos (design session)

- **Nevada suggested** a way to free the local space of cloud photos Seura had downloaded, since Windows lets an app ask the sync service to make a file cloud-only again.
- **Claude** confirmed it's possible on Windows (the attribute Explorer's Free up space sets), uncertain on the Mac until signing, and suggested it as a small command after 1.0.
- **Nevada then proposed** leaving it to Explorer and Finder and explaining it in the user guide, since cloud folders have become a large part of Seura and deserve a section of their own. Claude agreed it was the better choice: Seura reads and downloads cloud photos but doesn't manage storage, and the operating systems already do this well. The milestone plan's user guide now includes it.
