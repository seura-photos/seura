# M4 slices 1 to 3: design review (design session)

- **The formulas appendix began** (edit-format #5) with its conventions and `seura.exposure`. Claude reviewed it and agreed with the main choices: no clipping between operations, luminance from Display P3's own coefficients (checked against the standard matrix), test vectors instead of images for operations that work pixel by pixel, and a tolerance loose enough for half-precision floats. Two wording changes asked for: "1" is the photo's reference white rather than "the brightest white it holds", so HDR photos (#60) don't contradict it later; and a clear rule for values below 0. And a note for later: neighborhood and position-dependent operations need small test images, not single colors.
- **Revert keeps what undo couldn't restore whole:** other apps' operations and operations turned off (EDT-10, Claude Code's finding). The confirmation mentions other apps' edits when there are any.
- **Leaving an unanswered "Keep yours or load theirs?"** loads theirs, as Claude Code built it, plus a message so the lost changes aren't silent.
- **#112:** the free Apple Development certificate didn't help. Claude recommended against asking Finder through Apple Events (a permission to control Finder is too broad an ask) and for a Show in Finder button meanwhile, with Developer ID tested before the beta.
