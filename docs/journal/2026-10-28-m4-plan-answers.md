# M4 planning questions (design session)

- **Claude Code drafted the M4 plan** (#129) and raised six questions. Nevada had asked the design session to settle them; Claude's answers, mostly agreeing with Claude Code's suggestions:
  - **The formulas appendix** for the edit format is written by Claude Code, one operation at a time with reference images, in edit-format pull requests the design session reviews, and reviewed again as a whole before the format freezes at 1.0 (M7). The format's guide now says so.
  - **Unbuilt Editor items** (Copy edits, Export, presets) are left out until M5, as the Windows ⋯ menu leaves out Settings.
  - **Crops follow** a rotation or flip; **the crop grows back** as straightening returns toward zero, while crop mode is open.
  - **One change from Claude Code's suggestion:** Brightness shows on the same −100 to 100 scale as the other light sliders (25 to a stop), not in stops with decimals. Seura is for people who used Picasa, not Lightroom, and one scale reads more simply. The edit format still stores stops.
  - **Enhance** replaces only its seven settings, analyzes the photo before them so it gives the same result when pressed again, and is one undoable change.
