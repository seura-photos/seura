# Ratings (M3 slice 2)

- **Rating from the keyboard and the Info panel.** `0` to `5` rate the selection in the Library or the photo in the Viewer, anywhere except while typing in a field. The Info panel's five stars are now buttons. Both go through slice 1's `change_photos`, and the grid's badges and the panel follow when the library reports the change.
- **Clicking the current rating's star clears it.** Lightroom and Apple's Photos do the same, and it gives the mouse a way to clear a rating, since `0` is keyboard-only. The button says so ("Clear rating"). Decided by Claude Code; for the design session to confirm.
- **Mixed ratings** (TAG-8): empty stars with "Mixed" beside them, replacing M2's "Not all the same". Choosing a star rates all the selected photos.
- **Read-only folders** (TAG-7): the line "This folder is read-only, so tags and ratings can't be saved here." sits above the stars, which stay in place, disabled. `0` to `5` show the same words as a notice. A selection where only some photos are read-only can still be rated; the notice then says how many weren't changed.
- **A gap in the wireframes: where a notice goes in the Viewer.** The Library shows the last action's notice under the FOLDERS heading, but the Viewer covers the sidebar. Claude Code put the Viewer's notices in its status bar, between the zoom level and the key hints, showing only notices from while it's open. Raised for the design session. The key hints now include "0–5 rate".
- **The same notice twice** is now announced twice to screen readers: notices go through one `say` action that counts them.
- **Screenshots showed two problems,** taken with Nevada clicking in a development build on a generated test library (its own `SEURA_DATA`, with one folder made read-only with `icacls`), while Claude Code captured the window:
  - **The grid's rating badges were barely readable in light mode:** the light theme's dark gold on the badge's dark overlay. The badge sits on the overlay in both modes, so it now uses the dark theme's gold everywhere, as a new token, `overlay.ratingOnPhoto`, in `design/tokens.json`. The badge existed in M2, but no photo had a rating until now.
  - **A notice stayed after leaving its folder:** the read-only notice still showed in another folder. A notice now goes when another folder is chosen.
- **For the design session: the empty stars are faint.** `ratingOff` is about 1.5:1 against the light panel and 2:1 against the dark one. Now that the stars are buttons, accessibility guidelines ask for 3:1. Disabled stars also look much like empty ones; the read-only line above them carries the meaning.
- The development server's live reload once left the app blank after the store changed; restarting fixed it. Development only.
