# Add folder moves to the Folders heading

- **Nevada noticed** that with many folders in the tree, "+ Add folder" at the bottom of the list scrolled out of sight. He'd have put it at the top, but deferred to common practice.
- **Claude's recommendation, which Nevada accepted:** a + button in the FOLDERS heading, which stays in view while the tree scrolls. Apps either pin an add command to the bottom of the sidebar (Notes) or put a + in the section's heading (Lightroom's Folders panel). The heading wins here because the sidebar gains a Tags section in M3: a pinned bottom button would end up below the tags, far from the folders it adds. Its tooltip and accessible name say "Add folder".
- **The last action's notice** ("Added. Scanning for photos…") moved up under the heading for the same reason.
- **The styled mockup** still shows "+ Add folder" under the tree; the design session will update it.
