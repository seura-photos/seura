# Opening photos elsewhere: Nevada's answers (M2 slice 9)

- **Where the commands live.** Nevada chose the right-click menu on both platforms, for consistency, unless Mac practice says otherwise. Claude checked Apple's guidelines: context menus are normal on the Mac, but they're hidden by default, so their items belong in the menu bar too. So on the Mac, Show in Finder and Open in Default App are also in the File menu (⌥⌘R and ⌥⌘O), greyed out until a photo is chosen. Windows has no menu bar (Nevada, 2026-10-21); Shift+F10 opens the menu from the keyboard.
- **Opening many at once.** The first version disabled Open in default app above 20 photos. Nevada pointed out a disabled item doesn't say why. Claude found that Windows hides Open from Explorer's menu above 15 files, "to prevent accidental actions on large numbers of files", which has the same problem. So above 15 Seura asks instead: "Open 34 photos? Depending on the app, each may open in its own window." Nevada suggested the second sentence: the default app may open them all in one window, so Seura shouldn't promise many.
- **Cloud-only photos.** Nevada wanted a warning before opening cloud photos elsewhere downloads them all. Claude suggested folding it into the same question, and asking only for several: one photo opens as asked, as it does in the Viewer. "4 of them are in the cloud and will be downloaded to this computer." Cancel has the focus.
- **The spec:** BRW-8 doesn't describe any of this yet; Claude Code wrote it up for the design session.
