# Keys for Review (design session)

- **Nevada asked,** testing M6, for a key to start a review and for X in the Library. Claude Code suggested R, and X as a mark/unmark toggle anywhere.
- **R starts a review** in the Library, agreed.
- **X in the Library only unmarks.** Claude pointed out that a mark made outside a review waits for some later review that may never include it: a second, open-ended way to delete beside Delete, needing a filter to gather marks. Nevada had mostly wanted to clear marks without opening a review, and agreed: erring on the side of caution. Marking stays in Review, where the summary acts on it; it can be revisited if that proves too strict.
