# Search (M3 slice 6a)

- **Slice 6 is in two parts:** search (FND-2) first, then filters (FND-1), each sizeable on its own.
- **The search box sits in the header,** after the app's name, as in the styled mockup ("Search file names and tags"). Ctrl+F (Cmd+F) goes to it from anywhere in the Library.
- **As the design session answered:** while searching, the grid shows results from every folder, headed "Results for "beach"" with the number found; the sidebar has no selection; Esc clears the search and goes back to the folder or tag selected before; and choosing a folder or tag ends it. Emptying the box ends it too, the same as Esc.
- **Matching** is the index's search, which since slice 3 ignores case and Unicode form (TAG-2), over file names and tags. The Viewer goes back to "Results" from a search.
- **Noticed in the mockup, not built here:** undo and redo buttons in the toolbar, beside Enhance. Slice 5 gave them keys and, on the Mac, the Edit menu; the buttons are left for when the toolbar's other actions (Enhance, Edit, Export) arrive in M4, unless Nevada wants them sooner.
