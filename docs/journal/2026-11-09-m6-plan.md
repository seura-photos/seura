# 2026-11-09: Drafting the M6 plan

- **Nevada asked Claude Code to draft the M6 plan** once M5 was recorded. It has eight slices, 0 to 7, with fifteen questions for a design session, each with a suggestion.
- **The documents disagree in three places,** which Claude Code found while drafting and left as questions: the banner's words (the spec and the wireframes), the action bar's order (the user flows against the wireframes and mockups), and the summary's counts (the spec and the user flows against the wireframes).
- **Questions the spec leaves open that shape the code:** where a mark is kept (Claude Code suggests a file in `Seura Photos`, since a mark in the edit file would bring back the cloud services' deletion notices), and what "new" means, since the index doesn't record when a photo arrived.
- **A trap in "new since the previous launch":** with no usable snapshot, every photo would look new. Clearing the cache, or a build that changes the snapshot's layout, must not bring up a banner for the whole library.
