# 2026-11-24: No rating or tag keys in the Editor (#293, reversed)

- **Where it came from:** the user guide's fact sheet (open question 5). The user flows say single-letter keys work in every view, and list 0–5 and T with no exceptions, but the Editor handles neither. The design session recommended that the Editor accept them. Claude Code offered that as the recommended choice, and Nevada chose it the same day.
- **Built, then not merged:** #294 made 0–5 rate the photo being edited and T open the tag picker, through the Library's write path. It also told the Editor about the new step in the photo's history, so its undo stayed correct. CI passed.
- **Reversed by Nevada while testing it on Windows:** the keys worked, but the Editor doesn't show the rating or the tags, so a key press changed something the user couldn't see. Nevada had already settled this on 2026-10-29, when undoing a rating from the Editor showed only "Undid Rating": they ruled out showing ratings and tags there, because "the editor is for editing the photo itself, not its metadata" ([2026-10-29-editor-undo](2026-10-29-editor-undo.md)). Setting them there goes against the same principle. Nevada asked to reconsider, and Claude Code agreed: when offering the keys, it hadn't connected the two decisions, and should have.
- **The outcome:** #294 was closed without merging, and #293 closed as not planned. The Editor stays as it was, the one exception to single-letter keys working in every view. The design session is asked to say so in the user flows. The guide keeps its line that 0–5 and T do nothing in the Editor.
- **Also decided by Nevada that day, from the same questions, and unaffected:** Seura is for Apple silicon Macs only, made official for 1.0. The design session updates the technical design.
