# 2026-11-24: Rating and tag keys in the Editor (#293)

- **Where it came from:** the user guide's fact sheet (open question 5). The user flows say single-letter keys work in every view, with 0–5 and T listed without exceptions, but the Editor took neither. The design session recommended making the Editor accept them, and Nevada decided so on 2026-11-24. The user flows already say it, so no document changes.
- **Also decided by Nevada that day, from the same questions:** Seura is for Apple silicon Macs only, made official for 1.0. The design session updates the technical design.
- **How:** in the Editor, 0–5 rates the photo being edited, and T opens the tag picker beside its name, with the same message as elsewhere (INT-6). Neither works while crop or red-eye mode has the keys, or while typing. A rating goes through the Library's write path, as everywhere else. Any slider change waiting to be autosaved is saved first, so the two stay separate steps in the photo's history.
- **One thing that needed care:** the watcher doesn't report Seura's own writes, so the Editor wouldn't have known that its photo's history had a new step, and its undo button would have been out of date. Now the Library tells the Editor after a rating or tag change to the photo it has open, the same way it does after another app changes the file. A tag or rating is never a conflict, since neither is one of the Editor's edits.
- **The Library's undo also records it.** After leaving the Editor, Ctrl+Z in the Library undoes the rating, as it would one given there. In the Editor, Ctrl+Z steps back through the photo's own history, which now includes it.
