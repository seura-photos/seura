# The Welcome screen (M2 slice 2)

Claude Code built the first-run Welcome screen from its wireframe and the tokens (no styled mockup existed).

- **It names Seura's folder** (decision 0015): "Seura keeps its settings and thumbnails in the Seura Photos folder in your home folder: C:\Users\…\Seura Photos".
- **Folders by id, not by path:** the core offers the Pictures folder and any folder picked in the system dialog, each with an id, and Get started sends the ids back. The UI never sends a path of its own, keeping decision 0009's rule even for adding folders.
- **Synced folders, recognized generically:** on Windows, the Cloud Files API (`CfGetSyncRootInfoByPath`) says whether a folder is inside any sync root, OneDrive, iCloud for Windows, Dropbox, or Box, and names the provider; Claude confirmed it recognizes Nevada's OneDrive folder. On macOS, synced folders live under `~/Library/CloudStorage` and `~/Library/Mobile Documents`. If the cache would be synced, the note offers another place, and the library switches to it at once.
- **A switch to see it again:** `SEURA_WELCOME=1` shows the Welcome screen on a computer that already has settings, without saving anything unless Get started is pressed. Claude used it to capture the screen on Nevada's PC, plain and pseudo-translated; his settings file was byte for byte unchanged afterwards.
