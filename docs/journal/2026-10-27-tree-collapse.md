# Expanding and collapsing the sidebar trees (design session)

- **Nevada suggested** Expand all and Collapse all buttons for the FOLDERS and TAGS trees.
- **Claude's recommendation, which Nevada accepted:** Collapse all, yes, as a button in each heading, keeping the way to the selection open so the grid never shows a folder the sidebar hides. A whole-tree Expand all, no: on a large OneDrive library it would make hundreds of rows, the reason Nevada had both trees start closed. Instead, the conventions for expanding one branch: Alt- or Option-click on an arrow (as in Finder), "Expand all beneath" in the right-click menu, and `*` from the keyboard (the ARIA tree pattern). Explorer, Finder, and VS Code also leave out a global expand-all.
