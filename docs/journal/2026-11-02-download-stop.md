# Stopping downloads, and OneDrive's deletion notice (design session)

- **Testing Enhance's downloads on real OneDrive photos (#201),** Nevada found that Stop can't stop a download already under way: Seura stops waiting, but its read keeps running, and on the Mac the photo still arrived. The spec had said the Mac stops an abandoned download, from a measurement that killed a separate process. Claude Code suggested saying only that the download may still finish on either system, and leaving a real cancel out; Claude agreed. The finished message now says a photo already downloading may still arrive.
- **Nevada proposed** warning before an empty edit file goes to the Trash, since OneDrive on the Mac answers with its own "deleted everywhere" notice (#200). Claude recommended a quieter form: a one-time message per cloud service the first time it happens, explaining that the photo isn't affected, rather than a dialog with "Don't show this again" before a one-click change. For M5 or later.
