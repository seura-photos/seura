# Zoom in the Editor (design session)

- **Nevada noticed** that the Editor can't zoom, though the Viewer can. It had never been discussed: the Editor's wireframe simply had no zoom.
- **Claude's recommendation, which Nevada accepted:** the Viewer's zoom in the Editor too, with the same controls, since red-eye (EDT-7) needs it to reach small eyes and highlights and shadows are judged up close. Where a tool uses the drag (red-eye), Space-drag pans, as in Lightroom and Photoshop. Crop and straighten always show the whole photo. Compare keeps the zoom; the next photo returns to Fit.
