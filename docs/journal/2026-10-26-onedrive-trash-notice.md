# OneDrive's own notice when an edit file goes to the Trash

- **Nevada's check on the Mac (slice 2, after merging):** rating a photo and then clearing the rating sent its edit file to the Trash, as FIL-1 asks. The photo was in his OneDrive folder, so OneDrive showed its own notice: deleting a file on this computer deletes it everywhere.
- **Nevada's view, which Claude Code shares:** that's still what should happen, and Seura shouldn't try to get around it. The only ways round it would be deleting permanently, which CLAUDE.md's rule 5 forbids, or leaving empty edit files beside photos, against FIL-1 and the edit format's advice. OneDrive is right to warn: the file is leaving every device. To be documented, so users aren't surprised.
- **What the notice is** (Nevada, on the Mac): a dialog in the middle of the screen saying deleted files are removed everywhere, with a "Don't show this reminder again" checkbox and two buttons, "Got it" and "Open OneDrive Recycle Bin". It's informative only: there's no way to refuse the deletion, and the file is in the Trash either way. It stopped appearing after a few times, without the checkbox, apparently because OneDrive noticed several deletions in a short time.
- **A worry that turned out not to apply:** Claude Code asked what would happen if the deletion were refused, since the file in the Trash still holds the rating just cleared, so the rating would come back. The dialog has no way to refuse, so nothing to handle.
- **Also evidence for slice 9 (BRW-9):** the design session asked whether OneDrive shows a dialog of its own when Seura moves a file to the Trash. On the Mac it does, and it's only informative. On Windows it doesn't (Nevada): the edit file is deleted as expected, with no notice. OneDrive for Windows has a setting, "Notify me when a large number of files are deleted in the cloud", which a single file doesn't reach. The two platforms differ, which is fine. Still to measure in slice 9: where an online-only photo goes, the local Recycle Bin or Trash or only OneDrive's own.
